# KeyMacro

Windows 11向けのキーボード・マウス割り当てアプリです。

## 起動

.NET 10 デスクトップ ランタイムが必要です。ソースからビルドする場合は .NET 10 SDK を使います。

```powershell
dotnet build -c Release
.\bin\Release\net10.0-windows\KeyMacro.exe
```

## 割り当て

1. 「通常レイヤー」または「SKレイヤー」を選び、「＋ 追加」を押します。
2. 「割り当て元」でキーまたはマウスボタンを選びます。左右・中央・サイドの5ボタンに対応します。
3. 動作を選んで保存します。
   - **入力の置き換え** — 元の入力を押している間、変換先のキーやマウスボタンを押します。
   - **シーケンス** — 入力、待機、文字入力、コマンドを上から順に実行します。「押下」と「解放」を分けて組み合わせると、複数の入力を重ねられます。
   - **SKキー** — 通常レイヤーで指定します。SKキーを押している間の新しい入力にはSKレイヤーの割り当てを使います。SKレイヤーで未設定の入力はそのまま通過します。
4. 「有効にする」を押し、操作対象のアプリに切り替えます。

起動時は停止中です。**F12** で有効・停止を切り替えます。**Esc** は実行中のシーケンスをすべて中断し、シーケンスが押していた入力を解放します。Esc自体も操作対象に届きます。F12とEscは割り当て元として予約されています。

## 繰り返しの例

「例を追加」で次のシーケンスが入り、割り当て元を選んで保存できます。

| 順番 | 動作 | 設定値 |
| --- | --- | --- |
| 1 | 長押し | W、1,000 ms |
| 2 | 押して離す | Space |
| 3 | 待機 | 500 ms |
| 4 | 長押し | S、1,000 ms |

「Escを押すまで繰り返す」にチェックが入っています。「押して離す」は約30 ms押下します。待機時間の精度はWindowsのスケジューリングに依存します。

## 設定と動作環境

- 設定は `%LOCALAPPDATA%\KeyMacro\bindings.json` に保存します。
- コマンドは `cmd.exe` で実行し、終了後に次のステップへ進みます。非ゼロの終了コードでシーケンスを中断します。
- Windowsの権限分離により、管理者権限で実行されているアプリには通常権限のKeyMacroから入力を送信できません。[Microsoft Learn の SendInput 仕様](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendinput)
- レイヤー判定とシーケンス処理は `MacroEngine.cs`、Windowsの入力監視・送信とコマンド実行は `WindowsInput.cs` にあります。Ubuntu対応には対応する入力バックエンドとGUIが必要です。
